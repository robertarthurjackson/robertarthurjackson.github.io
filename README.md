# robroth

Personal website. Plain HTML/CSS, no build step, GitHub Pages ready.

- `index.html` — homepage (stub)
- `resume/index.html` — C.V.
- `css/style.css` — shared styles (screen, dark mode, print)

## Run locally

    ./serve.sh

then open http://localhost:8090/ (Resume at http://localhost:8090/resume/).
